My Portfolio Website

This is a Next.js project bootstrapped with create-next-app.

Overview

This is the repository for my personal portfolio website. The site is designed to showcase my skills, projects, and web development journey. It features detailed project pages with descriptions, links to live demos, and GitHub repositories. The site is built with React, TypeScript, Next.js, and Tailwind CSS to create a responsive and user-friendly experience.

Features

Dynamic Project Pages: Each project has its own dedicated page with a detailed introduction, description, images, and relevant links.
Responsive Design: Optimized for viewing on both desktop and mobile devices.
Dark Mode Support: Automatically adjusts based on the user's system preferences.
404 Page: Custom "Page Not Found" error page for handling incorrect URLs.
Technologies Used

React: Modular, reusable components for dynamic content rendering.
TypeScript: Type-safe JavaScript for error prevention and improved code reliability.
Next.js: Server-side rendering for improved SEO and page performance.
Tailwind CSS: Utility-first CSS framework for rapid styling.
JSON: Used to manage project data dynamically.
